How live updates work with Google Sheets:
  1. Create a new Google Sheet at sheets.new with columns: Name and Company.
  2. In Google Sheets, go to Extensions > Apps Script, paste the code from google-apps-script.js, and click Deploy > New deployment > Web app (Access: Anyone).
  3. Copy the Web app URL into the field below.
  4. In Google Sheets, click File > Share > Publish to web > select CSV format > copy that CSV link below.
The admin form submits new rows directly to this endpoint.
The public celebration page and this admin panel read live data from this link.
